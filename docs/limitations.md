# Batas implementasi dan interpretasi

Bagian runnable: registry/schema, safe HTTP, web allowlist + robots + Crawl4AI, public YouTube adapter yang diuji fixture, semua platform contract/import, penyimpanan idempotent dan snapshot, normalisasi, ER/gate/dimension ranking, ringkasan isu preliminary, export dan dashboard HTML lokal.

Bagian yang belum tersedia: API Instagram/TikTok/Threads/Facebook/LinkedIn; fetch RSS jaringan; earned API search; account discovery otomatis yang menghasilkan akun approved; pengambilan follower; PostgreSQL; provider berlisensi; LLM/OCR/vision/transkrip; ekstraksi fakta/biaya produk otomatis; import harga terintegrasi; news syndication/story clustering; composite end-to-end dan rekomendasi otomatis dari sampel memadai. Tabel cadangan tidak berarti collector sudah ada. Tidak ada API yang “sukses” hanya karena mengembalikan list kosong.

Probe key YouTube i18nRegions.list sudah LIVE_OK, tetapi belum ada channel approved untuk pengumpulan kompetitor. Format Shorts/long tidak ditebak; metrik turunan diblokir default sesuai status izin. Meta docs 429; snapshot dokumentasi tidak diklaim lengkap. X telah dihapus dari build gratis dan host API-nya diblokir. TikTok Research bukan jalur komersial bank. Semua memiliki impor CSV/JSON yang diuji.

Live web saat implementasi hanya satu halaman Mandiri. Angka sosial, ranking riil, fakta harga serentak, legal status seluruh universe, launch date dan rekomendasi kampanye **belum dapat disimpulkan**. Account verification awal masih kosong; keterbatasan ini bukan tanda kompetitor tidak aktif. Klaim bisnis dari official press release tidak diambil sebagai angka sosial atau dicampur dalam skor.

Dashboard memfilter post/snapshot/content berdasarkan platform/brand/segment/ownership/format/WIB. Ranking tersimpan hanya memakai cohort/periode asal; perubahan tanggal menyembunyikan ranking dan agregat isu/conversation, bukan menghitung ulang subset dengan denominator lama. Filter brand tidak mengubah n peserta ranking asal. Issue aggregate tanpa brand-specific linkage disembunyikan jika brand/segment/format/ownership diseleksi. Trend adalah snapshot rate yang tersedia, bukan kurva historis rekaan.

Security boundary: URL allowlist tepat, DNS publik diperiksa, redirect tidak diikuti, tidak fetch tautan/subresources dari konten, tanpa shell/JS dari halaman. Resolver HTTP tidak melakukan DNS pinning; allowlist hanya boleh diedit operator tepercaya. Retensi dijalankan ketika pipeline/dashboard dibuka, bukan daemon; operator harus menjalankan aplikasi sebelum deadline sumber dan menghapus salinan export/backups di luar root secara terpisah. Pseudonimisasi/filter regex mengurangi PII tetapi bukan pengganti review teks sensitif. Raw evidence tidak disimpan default; hash tidak dapat menggantikan izin/audit sumber asli.
