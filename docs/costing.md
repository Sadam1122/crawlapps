# Biaya, retensi dan operasi

Mode gratis dikunci: `ALLOW_PAID_PROVIDERS=false` dan `MAX_COST_PER_RUN=0`. Mengaktifkan flag paid atau budget positif ditolak saat startup. RunBudget juga selalu menolak provider berbayar/biaya positif walau validasi konfigurasi dibypass. Harga unknown, negatif dan nonfinite diblokir sebelum request. API X, credential dan opsi CLI-nya dihapus; host x.com/twitter.com diblokir pada transport. Tidak ada pembelian, langganan, quota upgrade otomatis atau paid LLM.

HTTP memerlukan deklarasi biaya; web publik yang sudah dinilai dan YouTube menggunakan biaya moneter 0. Quota API bukan uang: saat quota habis, request berhenti sesuai status API; tidak ada fallback berbayar. Dry-run/offline tidak memanggil network. `check-apis` membatasi maksimal 3 request tanpa retry: web 2, probe YouTube 1. Status sumber lain diperiksa tanpa menukarkan App Secret atau mengarang access token. Hasil lokal: `data/health/api-check.json`.

Default timeout 25 detik, retry paling banyak 2, backoff exponential+jitter; Retry-After dipatuhi hingga 30 detik. Delay lebih besar menghentikan source untuk dijadwalkan ulang, tidak dipotong lalu memanggil terlalu cepat. 401/403 tidak di-retry; CAPTCHA berhenti. Circuit breaker menghentikan domain yang gagal berulang. Tidak ada proxy/identity rotation. Redirect diblokir untuk review, termasuk yang masih public; request API key tidak diteruskan ke host lain.

Raw HTML/response API tidak dipersistenkan. Extract minimal dan metadata/hash tersimpan untuk provenance. Retensi konservatif default **30 hari**; `RETENTION_DAYS` dapat memperpendek, maksimum efektif tetap 30 pada rilis ini. Sebelum pipeline/dashboard mengakses data, run yang mengandung snapshot kedaluwarsa dihapus beserta data yang tidak lagi direferensikan run lain dan export lokal run tersebut. Tidak ada background job; jalankan maintenance/aplikasi sesuai tenggat sumber, terutama bila aplikasi lama tidak dibuka.

Untuk permintaan penghapusan lebih awal: `uv run goldintel purge --run-id RUN_ID` (atau `--demo-data` sebelum subcommand untuk demo). Penghapusan hanya data lokal, tidak menghapus konten di platform. Root target diperiksa sebelum recursive deletion. Operator wajib menghapus backup, hasil unduhan dan salinan Excel di luar folder run jika aturan sumber mewajibkannya. Provider dengan kebutuhan retention/deletion lebih pendek harus dikonfigurasi sebelum impor. Jangan simpan raw jika izin hanya metadata/hash.

Log berada di DATA_DIR/logs, rotasi 5 MB dan 7 hari. Jangan memasukkan secret ke parameter URL atau file impor; token konfigurasi bertipe SecretStr, doctor hanya menyatakan missing/configured. Tidak ada status expired tanpa request autentikasi yang sah. PII disaring dari teks; profil penulis komentar tidak dikumpulkan.
